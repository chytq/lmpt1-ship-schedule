# โฟลเดอร์นี้คือ "ข้อมูลปลอม" สำหรับ Developer เท่านั้น

ทุกอย่างในโฟลเดอร์นี้เป็น**ข้อมูลสมมติ** ชื่อเรือ ปริมาณ Density ชื่อ Loading Master
สร้างขึ้นมาลอย ๆ ไม่เกี่ยวกับตารางเรือจริงเลยแม้แต่นิดเดียว

## มีไว้ทำไม

ไฟล์ Excel จริง (`Work plan for LO.xlsm`) ไม่ได้อยู่ใน repo — dev ที่ clone มาใหม่
จึงไม่มีข้อมูลให้รัน โฟลเดอร์นี้แก้ปัญหานั้น: สร้างข้อมูลปลอมที่มีโครงสร้าง
คอลัมน์เหมือนของจริงเป๊ะ จะได้พัฒนาและทดสอบได้ทันที

## วิธีใช้

```bash
python sample/make_sample_excel.py     # สร้าง sample_work_plan.xlsx
```

แล้วรันเว็บในโหมด dev — ดับเบิลคลิก `RUN_DEV.bat` ที่โฟลเดอร์แม่
หรือสั่งเอง:

```bash
set USE_SAMPLE=1
python app.py
```

เปิด http://localhost:5000 จะเห็น**แถบสีเหลืองเตือน**อยู่บนสุดตลอดเวลา
ว่ากำลังใช้ข้อมูลปลอม

## ตัวกันพลาด (สำคัญ)

มี 3 ชั้น กันข้อมูลปลอมหลุดขึ้นเว็บสาธารณะ:

1. **ไม่มี fallback** — เว็บจะหยิบไฟล์ในโฟลเดอร์นี้มาใช้ก็ต่อเมื่อตั้ง `USE_SAMPLE=1`
   เท่านั้น ถ้าไฟล์จริงหายไป ระบบจะขึ้น error ไม่ใช่เงียบ ๆ ไปใช้ข้อมูลปลอมแทน
2. **แถบเตือนบนหน้าเว็บ** — เห็นชัดตลอดว่าอยู่โหมดไหน
3. **`build_static.py` ปฏิเสธการ build** ถ้าอยู่ในโหมด `USE_SAMPLE=1`
   หรือหาไฟล์จริงไม่เจอ — จึง push ข้อมูลปลอมขึ้น GitHub Pages ไม่ได้เลย

## ห้ามทำ

- ห้าม commit `sample_work_plan.xlsx` ขึ้น git (กันไว้ใน `.gitignore` แล้ว)
- ห้ามเอาไฟล์ Excel จริงมาวางในโฟลเดอร์นี้
- ห้ามตั้ง `USE_SAMPLE=1` ถาวรบนเครื่องที่ใช้ publish เว็บจริง
